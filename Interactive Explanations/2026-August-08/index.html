01 The Problem
📖
What's the Problem?

Given word1 and word2, find a sequence of indices in word1 such that the characters at those indices form word2, with at most one position where the characters don't match (a wildcard). Return the lexicographically smallest such index sequence, or empty if impossible.

🃏
The wildcard twist: You get one free mismatch. At exactly one position, the character in word1 doesn't need to match word2. You want to use this wildcard as late as possible (to keep indices small/lex-earliest), but only if the remaining suffix can still be completed.

03 Intuition
🧠
Two-Pass Strategy

The algorithm uses a clever two-pass approach:

  • Pass 1 — Suffix matching (right to left): Build suf[j] — the latest index in word1 that can match word2[j] when scanning from the end. This tells us: "if I need to match word2[j..m-1], can the suffix of word1 handle it?"
  • Pass 2 — Greedy forward (left to right): Scan word1 left-to-right. If word1[i] == word2[j], take it (exact match). If not, check: can we use the wildcard here? Only if we haven't used it yet AND the remaining suffix can cover word2[j+1..m-1].
  • Greedy is correct because taking the earliest matching index produces the lexicographically smallest result.
💡
Why suffix precompute? When considering using the wildcard at position j, we need to guarantee that word2[j+1..m-1] can still be matched by the remaining characters in word1. The suffix array suf[j+1] tells us the latest possible start for that suffix match — if our current index i is before it, we're safe!
04 Approach
🗺️
Step-by-Step Approach

1. Build suffix array suf[j]

Scan word1 from right-to-left, word2 from right-to-left. When word1[i] == word2[j], record suf[j] = i and move j left.

2. Greedy forward scan

Scan word1 left-to-right. For each i, if word1[i] == word2[j], push i to answer and advance j.

3. Use the wildcard (once)

If characters don't match and wildcard is unused: check if j is the last char of word2, OR if suf[j+1] exists and i < suf[j+1]. If yes — use the wildcard!

4. Validate result

If j reached m (all of word2 matched), return the indices. Otherwise return empty array.

07 Full Code
C++ • solution.cpp 
class Solution {
public:
    vector<int> validSequence(string word1, string word2) {
        int n = word1.size(), m = word2.size();
        vector<int> suf(m, -1);          // suffix match array
        vector<int> ans;

        // Pass 1: Right-to-left suffix matching
        int j = m - 1;
        for (int i = n-1; i >= 0 && j >= 0; i--) {
            if (word1[i] == word2[j]) {
                suf[j] = i;              // latest match for j
                j--;
            }
        }

        // Pass 2: Greedy forward matching
        j = 0;
        bool used = false;              // wildcard flag

        for (int i = 0; i < n && j < m; i++) {
            if (word1[i] == word2[j]) {   // exact match!
                ans.push_back(i);
                j++;
            }
            else if (!used &&             // wildcard available?
                (j == m-1 ||             // last char → always ok
                 (suf[j+1] != -1 &&     // suffix exists
                  i < suf[j+1]))) {       // and we're before it
                ans.push_back(i);
                j++;
                used = true;             // wildcard consumed!
            }
        }

        if (j != m) return {};          // couldn't match all
        return ans;
    }
};

09 Complexity Analysis
📊
Time & Space Complexity
Time
O(n + m)
Two passes over word1:
one backward, one forward.
Each is O(n).
Space
O(m)
Suffix array suf[] of size m,
plus the result array ans.
🚀
Optimal! We scan each string at most twice. The suffix precomputation is the key insight that avoids an O(n·m) brute-force search for wildcard placement.
10 Key Takeaways
✅
Remember These
  • Suffix precompute is the enabler — it answers "can the rest be matched?" in O(1).
  • Greedy earliest pick produces lex-smallest result automatically.
  • The wildcard should be used as late as possible — only when characters don't match AND the suffix check passes.
  • Two conditions for wildcard: j == m-1 (nothing left) OR i < suf[j+1] (suffix can cover the rest).
  • This "one-mismatch subsequence" pattern appears in edit distance variants, approximate string matching, and DNA alignment.
  • Total time: O(n + m) — beautifully linear!
