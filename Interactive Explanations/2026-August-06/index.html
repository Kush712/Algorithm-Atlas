01 The Problem
📖
What's the Problem?

Given two integers n and t, find the smallest integer ≥ n such that the product of its digits is divisible by t.


For example, with n = 10, t = 2: the digit product of 10 is 1×0 = 0, and 0 % 2 == 0, so the answer is 10.

💡
Key insight: Since the answer is always close to n (within a small range), simple brute force works perfectly. Just check n, n+1, n+2, ... until you find a match!

03 Intuition
🧠
Why Brute Force Works

This problem might seem like it needs a clever math trick, but brute force is actually the right approach:

  • Small search space: The answer is always within a small range of n. You won't need to check thousands of numbers.
  • Digit product is cheap: Extracting digits and multiplying them is O(log n) — very fast per number.
  • Any number with digit 0: Has digit product 0, which is divisible by everything. So the answer is at most the next multiple of 10!
🔑
Fun fact: If n has a digit 0, then product = 0, and 0 % t == 0 for any t. So 10, 20, 30, 100, etc. are always valid answers!
04 Approach
🗺️
Step-by-Step Approach

1. Start with the current number n

Begin checking from the given number. Our candidate is n itself first.

2. Extract digits and compute product

Use num % 10 to get the last digit, multiply into product, then num /= 10 to remove it. Repeat until all digits are processed.

3. Check divisibility

If product % t == 0, we found our answer! Return this number.

4. If not, increment and repeat

Increment n++ and try again. The loop is guaranteed to terminate.

  • Digit Extraction: The % 10 / /= 10 pattern is fundamental for working with individual digits of a number.

07 Full Code
C++ • solution.cpp 
class Solution {
public:
    int smallestNumber(int n, int t) {
        while(true) {
            int num = n;
            int product = 1;             // init product

            while(num > 0) {
                int dig = num % 10;       // extract last digit
                product *= dig;            // multiply into product
                num /= 10;                // remove last digit
            }

            if(product % t == 0) {       // divisible? done!
                return n;
            }
            n++;                         // try next number
        }
    }
};

10 Key Takeaways
✅
Remember These
  • Digit extraction via % 10 and /= 10 is a fundamental pattern — memorize it!
  • Brute force is valid when the search space is provably small. Don't over-engineer easy problems.
  • Any number with a 0 digit has product 0, which is divisible by everything — this guarantees termination.
  • The while(true) + return pattern is idiomatic for "search until found" problems.
  • Space complexity is O(1) — no arrays, no hash maps, just simple variables.
  • This "digit product" concept appears in LeetCode 3345, 1015 (numbers with repeated digits), and Kaprekar's routine.
