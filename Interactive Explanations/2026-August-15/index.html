Find the length of the longest subsequence whose bitwise XOR of all elements is not zero.

🟡 Medium🔢 Bit Manipulation📐 Math⊕ XOR Properties🎯 Greedy
01 The Problem
📖
What's the Problem?

Given an array of positive integers, find the longest subsequence such that the XOR of all its elements is non-zero.


Key insight: The XOR of the entire array is either zero or non-zero. If it's non-zero, the answer is n (take everything). If it's zero, we must remove at least one element — the answer is n − 1.

💡
XOR property: If XOR of all elements is 0, removing any one element gives a non-zero XOR (since a ⊕ a = 0). So the answer is always either n or n−1!

03 Intuition
🧠
XOR is Self-Inverse
  • a ⊕ a = 0 — XOR with itself cancels out.
  • If total XOR = 0, removing element x makes XOR = 0 ⊕ x = x ≠ 0.
  • So: total XOR ≠ 0 → answer is n. Total XOR = 0 → answer is n − 1.
  • Edge case: if all elements are 0, even n−1 won't help — but the problem guarantees positive integers.
04 Approach
🗺️
Step-by-Step Approach

1. Compute total XOR

XOR all elements together in one pass.

2. Check if total XOR is non-zero

If yes, return n — the entire array works.

3. Otherwise return n − 1

Remove any one element to break the zero-XOR.

07 Full Code
C++ • solution.cpp
class Solution {
public:
    int longestSubsequence(vector<int>& nums) {
        int n = nums.size();
        int totalXor = 0;
        for (int x : nums)
            totalXor ^= x;
        return totalXor != 0 ? n : n - 1;
    }
};

10 Key Takeaways
✅
Remember These
  • a ⊕ a = 0 is the single most important XOR property.
  • Total XOR of a set determines whether you can form a non-zero XOR subsequence.
  • Greedy insight: always try taking everything first, then see what minimal change is needed.
  • This O(n) / O(1) solution hides behind a deceptively hard-sounding problem name.
