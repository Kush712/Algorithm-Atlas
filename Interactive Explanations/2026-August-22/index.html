01 The Problem
📖
What's the Problem?

Given an integer n, compute the digit sum and digit product of its digits. Then check if n is divisible by (sum + product).


For example, n = 123: digit sum = 1+2+3 = 6, digit product = 1×2×3 = 6, sum+product = 12. Since 123 % 12 ≠ 0 → false. Wait, actually 123 / 12 = 10.25, so it's not divisible!

💡
Two operations in one pass: You extract each digit once and simultaneously compute both the running sum and running product. Classic digit extraction with dual accumulators!

03 Intuition
🧠
Why It's Simple & Elegant

This problem is a perfect exercise in the digit extraction pattern:

  • Extract: Use n % 10 to get the last digit, n /= 10 to remove it.
  • Dual accumulate: Maintain two accumulators simultaneously — sum += digit and product *= digit.
  • Final check: One modulo operation: orig % (sum + product) == 0.
⚠️
Edge case alert: If any digit is 0, the product becomes 0, so sum + product = sum. Also, if n itself is 0, you'd be dividing by 0 — handle this carefully!
04 Approach
🗺️
Step-by-Step Approach

1. Save the original number

Store orig = n because we'll modify n during extraction but need it for the final check.

2. Initialize accumulators

Set sum = 0 (additive identity) and product = 1 (multiplicative identity).

3. Extract digits one by one

While n > 0: extract dig = n % 10, accumulate into both sum and product, then n /= 10.

4. Check divisibility

Return orig % (sum + product) == 0.

💾 Save & Restore
  • Digit Extraction: The % 10 / /= 10 pattern — fundamental for any "digit manipulation" problem.
  • Dual Accumulator: Tracking two running values (sum and product) in a single loop — efficient and clean.
  • Save Original: A critical pattern — if your loop destroys the input, save it first!
  • Modular Arithmetic: a % b == 0 checks exact divisibility — one of math's most useful operations.
07 Full Code
C++ • solution.cpp 
class Solution {
public:
    bool checkDivisibility(int n) {
        int orig = n;             // save original
        int sum  = 0;             // digit sum
        int prod = 1;             // digit product

        while (n > 0) {
            int dig = n % 10;       // extract last digit
            sum  += dig;              // accumulate sum
            prod *= dig;              // accumulate product
            n = n / 10;              // remove last digit
        }

        if ((orig % (sum + prod)) == 0) {
            return true;           // divisible!
        }
        return false;
    }
};

10 Key Takeaways
✅
Remember These
  • The % 10 / /= 10 digit extraction pattern is the most fundamental building block for digit manipulation problems.
  • Dual accumulators in a single loop are efficient — no need for separate passes for sum and product.
  • Always save the original (orig = n) before destructive loops — a common source of bugs!
  • Initialize sum to 0 (additive identity) and product to 1 (multiplicative identity) — not the other way around!
  • Watch for zero digits — they kill the product but not the sum.
  • This pattern appears everywhere: digit root, happy numbers, Armstrong numbers, Kaprekar numbers, and more.
