Problem of the Day

Stone Game VLeetCode #1563

Divide stones into two groups. Alice gets the smaller sum, and the larger sum is thrown away. Find her maximum possible score.

🔴 Hard🧠 DP➗ Divide & Conquer📈 Prefix Sums
01 The Problem
📖
What's the Problem?

You have a row of stones. Alice divides it into two non-empty parts. The part with the larger sum is discarded. She adds the smaller sum to her score and continues playing with that smaller part. If both sums are equal, she can choose either.


Return the maximum score Alice can achieve.

💡
Subproblems: This is a classic interval DP. To find the best score for subarray [L, R], we try every possible split point and recursively find the best score for the remaining part.

03 Intuition
🧠
Interval DP + Prefix Sums
  • To efficiently calculate the sum of any subarray during the DP, we precompute a Prefix Sum Array.
  • The state is defined by solve(l, r) representing the max score from stones between indices l and r.
  • We iterate a split point `i` from `l` to `r-1`. We compare `leftSum` and `rightSum`.
  • We memoize the results in a 2D table `t[501][501]` to avoid recomputing overlapping subproblems.
04 Approach
🗺️
Step-by-Step Approach

1. Prefix Sums

Build `prefix` array where `prefix[i]` is sum of first `i` stones.

2. Recursive DP Function

Create `solve(l, r)` that loops through all split points `i` between `l` and `r`.

3. Handle Sum Comparisons

If `leftSum < rightSum`, score is `leftSum + solve(l, i)`. If greater, use right part. If equal, take the max of both choices.

4. Memoization

Cache the result in `t[l][r]` before returning.

07 Full Code
C++ • solution.cpp
class Solution {
public:
    int t[501][501];
    vector<int> prefix;

    int getSum(int l, int r) {
        return prefix[r + 1] - prefix[l];
    }

    int solve(vector<int>& stones, int l, int r) {
        if (l == r) return 0;
        if (t[l][r] != -1) return t[l][r];

        int result = 0;
        for (int i = l; i < r; i++) {
            int leftSum = getSum(l, i);
            int rightSum = getSum(i + 1, r);

            if (leftSum < rightSum) {
                result = max(result, leftSum + solve(stones, l, i));
            } else if (rightSum < leftSum) {
                result = max(result, rightSum + solve(stones, i + 1, r));
            } else {
                result = max({result, leftSum + solve(stones, l, i), rightSum + solve(stones, i + 1, r)});
            }
        }
        return t[l][r] = result;
    }

    int stoneGameV(vector<int>& stoneValue) {
        int n = stoneValue.size();
        prefix.resize(n + 1, 0);
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + stoneValue[i];
        memset(t, -1, sizeof(t));
        return solve(stoneValue, 0, n - 1);
    }
};

10 Key Takeaways
✅
Remember These
  • Interval DP almost always uses a 2D array caching `dp[start][end]`.
  • Prefix sums are mandatory to avoid O(N) sum calculations inside the O(N³) loops.
  • When dealing with recursive max/min games, carefully outline the rules mapping to recurrence branches.
