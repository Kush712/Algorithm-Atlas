Can you make string t a subsequence of string s by replacing at most one character in t?

🟡 Medium📝 String🧠 DP🔍 Two Pointers📊 Suffix Array
01 The Problem
📖
What's the Problem?

You have two strings, s and t. You want to know if t is a subsequence of s. The catch? You are allowed to change exactly one character in t to any other character.

💡
Why Prefix & Suffix? If we replace t[j] with s[i], we need to know: Can the prefix t[0..j-1] be made a subsequence of s[0..i-1]? AND can the suffix t[j+1..m-1] be made a subsequence of s[i+1..n-1]?

03 Intuition
🧠
Precomputing Suffix Matches
  • If we iterate left-to-right matching t into s, we know how much of t's prefix we can greedily match.
  • But when we encounter a mismatch and decide to "replace" t[j] with s[i], how do we know if the REST of t can fit in the REST of s?
  • Solution: Precompute a suffix array! suf[j] stores the earliest index in s where the suffix t[j..m-1] can be fully matched.
04 Approach
🗺️
Step-by-Step Approach

1. Check Length

If t is longer than s, return false immediately.

2. Build Suffix Array

Iterate backwards through both strings. If s[i] == t[j], record suf[j] = i and move j left.

3. Iterate Forwards & Replace

Match greedily left-to-right. When a replacement is needed at t[j] using s[i], check if the remaining suffix `t[j+1]` can match in `s` starting after `i` (using our suf array: suf[j+1] > i).

06 Patterns Used
🧩
Design Patterns
🔍 Two Pointers
📊 Prefix & Suffix Arrays
  • Prefix & Suffix Precomputation: This pattern is extremely common when you are allowed to "remove one element" or "change one element" in an array or string. By knowing what happens to the left and to the right, you can test a change at `i` in O(1) time.
07 Full Code
C++ • solution.cpp
class Solution {
public:
    bool canMakeSubsequence(string s, string t) {
        int n = s.size(), m = t.size();
        if (m > n) return false;

        vector<int> suf(m + 1, n);
        int j = m - 1;
        for (int i = n - 1; i >= 0 && j >= 0; i--) {
            if (s[i] == t[j]) suf[j--] = i;
        }

        if (j < 0) return true; // Already a subsequence

        j = 0;
        for (int i = 0; i < n && j < m; i++) {
            if (s[i] == t[j]) {
                j++;
            } else {
                // Try replacing t[j] with s[i]
                if (j + 1 >= m || (suf[j + 1] != n && suf[j + 1] > i)) {
                    return true;
                }
            }
        }
        return false;
    }
};

10 Key Takeaways
✅
Remember These
  • "Change one element" -> Think Prefix / Suffix arrays.
  • Greedy subsequence matching is always optimal. If a subsequence exists, the greedy leftmost (or rightmost) match is guaranteed to find it.
