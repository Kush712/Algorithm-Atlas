Problem of the Day

Divisible GameLeetCode #3984

Choose a divisor k. Iterate an array: if divisible add it, if not subtract it. The running sum can never drop below 0. Find the k that maximizes the peak sum!

🟡 Medium📊 Array🧮 Math🏃 Kadane's Variant
01 The Problem
📖
What's the Problem?

You iterate over an array keeping a running score starting at 0. You choose a divisor k (2 ≤ k ≤ max element). For each element:

  • If nums[i] % k == 0: Add it to score.
  • Otherwise: Subtract it from score.
  • If score ever drops < 0, it resets to 0.

We need to find the `k` that generates the highest possible score at any point during this process. Tie-breaker goes to smaller `k`. Return `(bestScore * bestK) % MOD`.

💡
Why Kadane's? A running sum that resets to 0 when it drops below 0 is the exact mechanism of Kadane's Algorithm for Maximum Subarray Sum! The only twist here is that the values added/subtracted depend on divisibility by `k`.

03 Intuition
🧠
Brute Force works!
  • The constraint on max(nums) is likely small enough that testing every valid k is acceptable.
  • For each k, we just simulate the process in O(N).
  • The time complexity will be O(N * max(nums)). If `max(nums)` is up to 10^4 or 10^5, this easily passes within 1 second.
04 Approach
🗺️
Step-by-Step Approach

1. Outer Loop (k)

Iterate `k` from 2 to the maximum element in `nums`.

2. Inner Loop (Simulation)

For each `k`, iterate through the array maintaining `currDiff`. Add if divisible, subtract if not.

3. Kadane's Reset

Keep track of the peak `currDiff` (`maxDiff`). If `currDiff < 0`, reset it to 0.

4. Update Global Best

If this `k` produces a higher `maxDiff` than `bestDiff`, update `bestDiff` and `bestK`.

07 Full Code
C++ • solution.cpp
class Solution {
public:
    int MOD = 1e9 + 7;

    int divisibleGame(vector<int>& nums) {
        int n = nums.size();
        long long bestDiff = -1e18;
        int bestK = 2;

        for (int k = 2; k <= *max_element(nums.begin(), nums.end()); k++) {
            long long maxDiff = -1e18;
            long long currDiff = 0;

            for (int i = 0; i < n; i++) {
                if (nums[i] % k == 0) currDiff += nums[i];
                else currDiff -= nums[i];
                
                maxDiff = max(maxDiff, currDiff);
                if (currDiff < 0) currDiff = 0;
            }

            if (maxDiff > bestDiff || (maxDiff == bestDiff && k < bestK)) {
                bestDiff = maxDiff;
                bestK = k;
            }
        }
        return (int)((bestDiff % MOD * (bestK % MOD)) % MOD);
    }
};

10 Key Takeaways
✅
Remember These
  • Read constraints carefully! Sometimes an O(N*M) loop is perfectly fine if the problem constraints cap M to 10⁴.
  • Whenever dealing with sums that can grow large, switch from `int` to `long long` immediately to avoid overflow issues before taking the modulo at the end.
