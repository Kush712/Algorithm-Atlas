Problem of the Day

Minimum Total Cost
to Process All ElementsLeetCode #3987

You have initial resources `k`. Processing an element costs its value in resources. If you don't have enough, you can buy `k` resources for an escalating cost.

🟡 Medium📊 Array🏃 Simulation➕ Accumulator
01 The Problem
📖
What's the Problem?

You iterate through an array of processing costs. Your initial resources is k. To process an element nums[i], you must have at least that many resources.

  • If resources < nums[i], you perform operations to get more.
  • Each operation grants you k resources and increases your opCount by 1.
  • The cost of an operation is the current opCount, which is added to a totalCost.
💡
Simulation is the way: Just simulate the exact process described. The only trick is keeping track of the running totals and applying modulo 10^9 + 7 to the total cost to prevent integer overflow.

03 Intuition
🧠
Direct Simulation
  • Since we need to keep track of a growing opCount and add it to totalCost incrementally while resources are insufficient, a `while` loop inside our `for` loop perfectly matches the physical description of the problem.
  • Be sure to use `long long` for all accumulators since resources can spike above `nums[i]` and cost accumulates repeatedly.
04 Approach
🗺️
Step-by-Step Approach

1. Initialization

Set `resources = k`, `opCount = 0`, `totalCost = 0`.

2. Iterate Array

For each element, check if we have enough resources.

3. The Refill Loop

`while (resources < nums[i])`, add `k` to resources, increment `opCount`, and add `opCount` to `totalCost` (modulo 10^9 + 7).

4. Process Element

After the `while` loop finishes, we are guaranteed to have enough resources. Subtract `nums[i]` from `resources`.

07 Full Code
C++ • solution.cpp
class Solution {
public:
    int MOD = 1e9 + 7;

    int minTotalCost(vector<int>& nums, int k) {
        long long resources = k;
        long long opCount = 0;
        long long totalCost = 0;

        for (int i = 0; i < (int)nums.size(); i++) {
            while (resources < nums[i]) {
                resources += k;
                opCount++;
                totalCost = (totalCost + opCount) % MOD;
            }
            resources -= nums[i];
        }

        return (int)totalCost;
    }
};

10 Key Takeaways
✅
Remember These
  • When asked to simulate, write the literal simulation first. If it times out, then optimize. Often, the literal simulation is the intended answer!
  • Modulo arithmetic (`% MOD`) should be applied at every addition step to prevent silent integer overflow midway through the loop.
