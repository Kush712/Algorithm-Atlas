Find the Largest
Almost Missing IntegerLeetCode #3471

Given an integer array and a size k, find the largest integer that appears in exactly one subarray of size k.

🟢 Easy📊 Array#️⃣ Hash Table🔍 Case Analysis
01 The Problem
📖
What's the Problem?

You need to find the largest integer that appears in exactly one contiguous subarray of size `k`. If no such integer exists, return -1.

💡
Case Analysis is Key: Because we are dealing with subarrays of fixed size `k`, how an element is included depends heavily on whether `k == n`, `k == 1`, or something in between!

03 Intuition
🧠
Breaking Down by 'k'
  • If k == n: There is only ONE subarray (the entire array). EVERY element appears in exactly one subarray! Just return the maximum element in the array.
  • If k == 1: A subarray of size 1 is just a single element. An element appears in exactly one subarray if it appears exactly once in the entire array.
  • If 1 < k < n: Any element in the middle (not first or last) will be part of multiple overlapping subarrays of size k. Only the first and last elements can possibly be in exactly one subarray (if they also only appear once in the whole array).
04 Approach
🗺️
Step-by-Step Approach

1. Handle k == n

Return the maximum element in `nums` since there's only 1 subarray of size n.

2. Count Frequencies

Build a frequency map of all elements in the array.

3. Handle k == 1

Find the maximum element that has a frequency of exactly 1.

4. Handle 1 < k < n

Check if `nums[0]` or `nums[n-1]` have a frequency of 1. Return the max of those that do.

#️⃣ Frequency Map
  • Case Analysis: Instead of blindly simulating all subarrays (which would be slow), breaking down the logic by the value of `k` results in an O(N) solution.
07 Full Code
C++ • solution.cpp
class Solution {
public:
    int largestInteger(vector<int>& nums, int k) {
        int n = nums.size();
        if (k == n) {
            return *max_element(nums.begin(), nums.end());
        }

        unordered_map<int, int> freq;
        for (int num : nums) {
            freq[num]++;
        }

        if (k == 1) {
            int ans = -1;
            for (auto& [val, cnt] : freq) {
                if (cnt == 1) ans = max(ans, val);
            }
            return ans;
        }

        int ans = -1;
        if (freq[nums[0]] == 1) ans = max(ans, nums[0]);
        if (freq[nums[n - 1]] == 1) ans = max(ans, nums[n - 1]);
        return ans;
    }
};

10 Key Takeaways
✅
Remember These
  • When dealing with subarrays of fixed size, analyzing the boundary constraints (first/last elements vs middle elements) often reveals a trick to avoid O(N²) generation.
  • Middle elements are "covered" by multiple overlapping windows if `1 < k < n`.
