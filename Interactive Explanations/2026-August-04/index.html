01 The Problem
📖
What's the Problem?

You're given an array of integers nums. Find all the integers that are missing from the continuous range between the minimum and maximum values.


For example, given [4, 2, 1, 7], the range is [1, 7] and the missing numbers are 3, 5, 6.

💡
Key idea: If we sort the array first, then missing numbers become visible as gaps between consecutive elements. Just walk through the sorted array and collect any integers that should exist but don't!

03 Intuition
🧠
Why Sort + Scan?

Think of it as building a number line:

  • Unsorted: Numbers are scattered — you can't easily tell what's missing.
  • After sorting: Numbers line up in order. Now, if nums[i-1] = 3 and nums[i] = 7, then 4, 5, 6 are clearly missing!
  • The gap: For each pair of consecutive elements, fill in all integers between nums[i-1]+1 and nums[i]-1.
🔑
Edge case: If no numbers are missing (like [1,2,3,4,5]), consecutive elements differ by exactly 1 — no gaps, so the result is empty!
04 Approach
🗺️
Step-by-Step Approach

1. Sort the array

Call sort(nums.begin(), nums.end()). This arranges numbers in ascending order so gaps become visible.

2. Scan consecutive pairs

Loop from i = 1 to n-1. For each pair (nums[i-1], nums[i]), check if there's a gap.

3. Fill the gaps

For each gap, iterate j from nums[i-1]+1 to nums[i]-1 and push each j into the result.

4. Return the result

The result vector contains all missing integers, already in sorted order (since we processed gaps left-to-right).

07 Patterns Used
🧩
Design Patterns
🔢 Sort First
🔍 Gap Detection
📏 Linear Scan
📊 Consecutive Pair Analysis
  • Sort First: A classic technique — sorting reveals structure in unsorted data. Many array problems become trivial after sorting.
  • Gap Detection: After sorting, any gap between nums[i-1] and nums[i] greater than 1 indicates missing values.
  • Consecutive Pair Analysis: Comparing adjacent elements is a fundamental pattern — used in duplicate detection, gap finding, and range problems.
  • Linear Scan: A single pass through the sorted array suffices — simple and efficient.
08 Full Code
C++ • solution.cpp 
// leetcode problem 3731 find missing elements
// https://leetcode.com/problems/find-missing-elements/

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> findMissing(vector<int>& nums) {
        sort(nums.begin(), nums.end());  // Step 1: sort
        int n = nums.size();
        vector<int> ans;

        for(int i = 1; i < n; i++) {              // Step 2: scan pairs
            for(int j = nums[i-1] + 1; j < nums[i]; j++) {  // Step 3: fill gaps
                ans.push_back(j);
            }
        }
        return ans;                            // Step 4: done!
    }
};

int main() {
    Solution solution;

    vector<int> nums = {4, 2, 1, 7};
    vector<int> missing = solution.findMissing(nums);
    cout << "Missing: ";
    for(int num : missing) cout << num << " ";
    cout << endl;   // Output: 3 5 6

    vector<int> nums2 = {1, 9};
    vector<int> missing2 = solution.findMissing(nums2);
    cout << "Missing: ";
    for(int num : missing2) cout << num << " ";
    cout << endl;   // Output: 2 3 4 5 6 7 8

    vector<int> nums3 = {1, 2, 3, 4, 5};
    vector<int> missing3 = solution.findMissing(nums3);
    cout << "Missing: ";
    for(int num : missing3) cout << num << " ";
    cout << endl;   // Output: (empty — no gaps!)

    return 0;
}

Code What it does

10 Complexity Analysis
📊
Time & Space Complexity
Time
O(n log n + m)
Sorting takes O(n log n).
Scanning takes O(n + m) where
m = total missing numbers.
Space
O(m)
Result vector stores m
missing integers.
🚀
Can we do better? The sort dominates at O(n log n). If the range is small, you could use a boolean array / hash set to mark present numbers and find missing ones in O(n + range) time. But for most cases, the sort approach is clean and efficient!
11 Key Takeaways
✅
Remember These
  • Sort first — a powerful technique that transforms chaotic data into structured, scannable data.
  • After sorting, gaps between consecutive elements reveal missing numbers instantly.
  • The inner loop j = nums[i-1]+1 to nums[i]-1 only runs when there's actually a gap — very efficient.
  • Results come out already sorted — no extra sort needed!
  • Watch out for edge cases: consecutive array (no gaps), only 2 elements with a large gap, single element.
  • This "sort + scan" pattern appears in many problems: missing ranges, summary ranges, merge intervals, etc.
