Number of Elapsed Seconds
Between Two TimesLeetCode #3986

Given two times in "HH:MM:SS" format, find the total number of elapsed seconds between them.

🟢 Easy📝 String🧮 Math⏱️ Time Conversion
01 The Problem
📖
What's the Problem?

You are given a startTime and an endTime. Both are strings in the exact format "HH:MM:SS". The endTime is guaranteed to be later than or equal to startTime on the same day.

Calculate the difference between the two times, in seconds.

💡
Standardization is key: Convert both times entirely to seconds from midnight, and then simply subtract the two integers! No need to do complex carry/borrow arithmetic on minutes and hours.

03 Intuition
🧠
The "Seconds Since Midnight" Trick
  • Instead of subtracting seconds, borrowing from minutes, subtracting minutes, borrowing from hours...
  • Just find the absolute value in seconds for both strings: H * 3600 + M * 60 + S
  • Then do a single subtraction: endTimeInSec - startTimeInSec
04 Approach
🗺️
Step-by-Step Approach

1. Write a Helper Function

Create `toSeconds(string time)` to handle the conversion logic cleanly.

2. Extract Substrings

Use `.substr()` to pull out the 2 characters for hours, minutes, and seconds.

3. Convert to Integers

Use `stoi()` to parse the strings into integers.

4. Calculate and Subtract

Multiply and return the difference.

07 Full Code
C++ • solution.cpp
class Solution {
public:
    int toSeconds(string time) {
        int h = stoi(time.substr(0, 2));
        int m = stoi(time.substr(3, 2));
        int s = stoi(time.substr(6, 2));
        return h * 3600 + m * 60 + s;
    }

    int secondsBetweenTimes(string startTime, string endTime) {
        return toSeconds(endTime) - toSeconds(startTime);
    }
};

10 Key Takeaways
✅
Remember These
  • When the input format is strictly fixed (like "HH:MM:SS"), hardcoding the indices `0`, `3`, and `6` is the fastest and easiest way to parse it.
  • Avoid manual time arithmetic (borrowing 60s from minutes, etc). Always convert to the lowest common denominator first.
