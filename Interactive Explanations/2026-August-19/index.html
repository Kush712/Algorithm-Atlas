Problem of the Day

Sum of Integers with
Maximum Digit RangeLeetCode #3982

Find the digit range (max digit - min digit) for each number. Return the sum of all numbers that have the maximum digit range.

🟢 Easy🔢 Math📝 String📊 Aggregation
01 The Problem
📖
What's the Problem?

For an integer, its digit range is the difference between its largest digit and its smallest digit. For example, for 418, max digit is 8, min is 1, range = 7.


Given an array, calculate the digit range for every element. Find the maximum range among all elements, and return the sum of all elements sharing this max range.

💡
String or Math? You can convert each number to a string to iterate its digits, or repeatedly use `% 10` and `/ 10` to extract digits mathematically. Both are perfectly fine for this easy problem!

03 Intuition
🧠
Two-Pass vs One-Pass
  • Two-Pass: First loop computes and stores ranges, and finds the global max range. Second loop sums elements that match this max range.
  • One-Pass (Optimized): Keep a running `maxRange` and `currentSum`. If we see a range > `maxRange`, we update `maxRange` and reset `currentSum` to the current element. If we see a range == `maxRange`, we add to `currentSum`.
04 Approach
🗺️
Step-by-Step Approach

1. Helper Function

Write `getDigitRange(num)` that uses `% 10` and `/ 10` to find max and min digits and returns their difference.

2. Iterate Array

For each number, get its range.

3. Update Running Max/Sum

If `range > maxRange`, reset sum. If `range == maxRange`, add to sum.

07 Full Code
C++ • solution.cpp
class Solution {
public:
    int getDigitRange(int num) {
        int mx = 0, mn = 9;
        while (num > 0) {
            int digit = num % 10;
            mx = max(mx, digit);
            mn = min(mn, digit);
            num /= 10;
        }
        return mx - mn;
    }

    int sumOfMaxDigitRange(vector<int>& nums) {
        int maxRng = -1;
        int sum = 0;
        
        for (int x : nums) {
            int rng = getDigitRange(x);
            if (rng > maxRng) {
                maxRng = rng;
                sum = x;
            } else if (rng == maxRng) {
                sum += x;
            }
        }
        return sum;
    }
};
