Longest Substring of
One Repeating CharacterLeetCode #2213

Given a string and character update queries, after each update return the length of the longest substring consisting of a single repeating character.

🔴 Hard🌲 Segment Tree📝 String🔄 Point Update📊 Range Query
01 The Problem
📖
What's the Problem?

You're given a string s and a series of queries. Each query updates one character in the string. After each update, you need to find the longest contiguous substring where all characters are the same.


Example: "babacc" → update index 1 to 'c' → "bcbacc" → longest repeating = "cc" = 2.

💡
Why a segment tree? Brute force rescanning is O(n) per query. With a segment tree, each update and query runs in O(log n), supporting up to 10⁵ queries efficiently.

03 Intuition
🧠
Segment Tree with Merge

Each segment tree node stores:

  • pre — longest repeating prefix of the segment
  • suf — longest repeating suffix of the segment
  • mx — overall longest repeating substring in the segment
  • lc, rc — leftmost and rightmost characters
⚠️
Merge logic is crucial: When merging two children, if the right char of left child equals the left char of right child, the suffix of left + prefix of right may form a longer repeating substring crossing the boundary.
04 Approach
🗺️
Step-by-Step Approach

1. Build segment tree from string

Each leaf stores {pre=1, suf=1, mx=1, len=1, lc=char, rc=char}.

2. Define merge operation

Combine children: check if boundary characters match to extend runs across segments.

3. Point update

Update a leaf, then propagate the merge up to the root.

4. Query the root

After each update, tree[1].mx gives the global longest repeating substring.

  • Segment Tree: The go-to data structure for range queries with point updates in O(log n).

  • Prefix/Suffix Tracking: Storing boundary information enables correct cross-segment answers.
07 Full Code
C++ • solution.cpp
struct Node {
    int pre, suf, mx, len;
    char lc, rc;
};

Node merge(Node& l, Node& r) {
    Node res;
    res.len = l.len + r.len;
    res.lc = l.lc; res.rc = r.rc;
    res.pre = l.pre;
    if (l.pre == l.len && l.rc == r.lc)
        res.pre = l.len + r.pre;
    res.suf = r.suf;
    if (r.suf == r.len && r.lc == l.rc)
        res.suf = r.len + l.suf;
    res.mx = max({l.mx, r.mx, res.pre, res.suf});
    if (l.rc == r.lc)
        res.mx = max(res.mx, l.suf + r.pre);
    return res;
}

10 Key Takeaways
✅
Remember These
  • When queries are dynamic updates + global queries, think segment tree.
  • Segment tree nodes can store custom structs — not just sums or mins.
  • The merge function is the heart of a segment tree — get it right and everything else follows.
  • Tracking prefix, suffix, and boundary characters enables cross-segment answers.
  • This pattern applies to: longest consecutive 1s with flips, maximum subarray with updates, etc.
