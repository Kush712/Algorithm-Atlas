Problem of the Day

Distinct Gate Paths
to LCA LeetCode #3973

Given a tree with designated gate nodes, find all distinct paths from gates to the Lowest Common Ancestor of two target nodes.

🔴 Hard 🌳 Tree 🔗 LCA 📊 DFS 🗺️ Path Counting
01 The Problem
📖
What's the Problem?

You're given a rooted tree with n nodes, a list of gate nodes, and two target nodes u and v. Find the Lowest Common Ancestor (LCA) of u and v, then count the distinct path lengths from each gate to the LCA.


The LCA is the deepest node that is an ancestor of both u and v. Gates that are in the subtree rooted at the LCA contribute distinct paths based on their depth difference.

💡
Core insight: First find the LCA using standard DFS traversal, then compute path lengths from each gate to the LCA. The key is understanding tree ancestry relationships.

03 Intuition
🧠
Breaking Down the Approach

This problem combines two classic tree techniques:

  • LCA Finding: Use DFS to record parent and depth of every node, then walk up from both u and v until they meet.
  • Path Counting: For each gate, compute the path length to the LCA by traversing parent pointers upward.
  • Distinct Filtering: Collect all path lengths and return only unique values.
⚠️
Edge case: A gate node might be the LCA itself — in that case the path length is 0. Make sure not to skip it!
04 Approach
🗺️
Step-by-Step Approach

1. Build the adjacency list

Convert the edge list into an adjacency list representation for efficient traversal.

2. DFS from root to record parent & depth

Run DFS from node 0, recording parent[node] and depth[node] for every node.

3. Find LCA of u and v

Bring both nodes to the same depth, then walk up simultaneously until they meet at the LCA.

4. Compute distinct gate paths

For each gate, count hops to the LCA via parent pointers. Collect unique path lengths and sort them.

  • Tree DFS: The fundamental traversal pattern — record parent/depth in a single pass.

  • Parent Pointer Walking: Count hops by following parent links — a classic path measurement technique.
07 Full Code
C++ • solution.cpp 
class Solution {
public:
    vector<vector<int>> adj;
    vector<int> parent, depth;

    void dfs(int node, int par, int d) {
        parent[node] = par;
        depth[node] = d;
        for (int &child : adj[node])
            if (child != par)
                dfs(child, node, d + 1);
    }

    int lca(int u, int v) {
        while (depth[u] > depth[v]) u = parent[u];
        while (depth[v] > depth[u]) v = parent[v];
        while (u != v) { u = parent[u]; v = parent[v]; }
        return u;
    }

    int countPaths(int node, int target) {
        int count = 0;
        while (node != target) {
            node = parent[node];
            count++;
        }
        return count;
    }
};

10 Key Takeaways
✅
Remember These
  • The LCA is found by leveling depths then walking up in tandem — a fundamental tree technique.
  • Parent pointers from DFS enable walking from any node to any ancestor.
  • Always deduplicate results when the problem asks for "distinct" values — use a set or sort + unique.
  • Tree problems often decompose into: build → DFS → query. Master this pipeline.
  • For production code, prefer Binary Lifting LCA for O(log n) queries on large trees.
