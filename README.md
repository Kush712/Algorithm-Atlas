# 📖 About

Welcome to **Algorithm Atlas**.

This repository is my personal coding journal where I solve the **LeetCode Problem of the Day** every single day.

Each solution is carefully written with:

- ✅ Clean & Readable C++ Code
- 🧠 Detailed Explanation
- ⚡ Optimized Approach
- 📊 Time & Space Complexity
- 💡 Key Observations
- 🎯 Interview Tips (whenever applicable)

The goal is simple:

> **Stay consistent, improve problem-solving skills, and master Data Structures & Algorithms.**
